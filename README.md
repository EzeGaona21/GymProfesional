# 🏋️‍♂️ GymPro

Aplicación móvil para gestionar rutinas de entrenamiento y progreso personal.  
Desarrollada en **Kotlin** con **Android Studio** y **Firebase**.

## Funcionalidades
- Registro e inicio de sesión con Firebase Authentication  
- Creación, edición y eliminación de rutinas  
- Guardado en Firestore  
- Interfaz moderna y simple
