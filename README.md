# GymPro — Rutinas de entrenamiento

App Android para gestionar rutinas de entrenamiento, desarrollada en Kotlin con Android Studio.

## Qué hace

- Registro e inicio de sesión de usuarios.
- Rutinas por grupo muscular (pecho, espalda, piernas y otros) con series, repeticiones y descanso.
- Alta, edición y baja de rutinas.
- Trae 10 rutinas de ejemplo cargadas.

Todos los datos se guardan en una base SQLite local, en el mismo teléfono.

## Tecnologías

Kotlin · Android Studio · SQLite

## Versiones

La primera versión del proyecto usaba Firebase Authentication y Firestore. En esta versión el login y las rutinas pasaron a una base SQLite local.

## Cómo correrlo

Abrí el proyecto en Android Studio y ejecutalo en un emulador o en un dispositivo Android.
